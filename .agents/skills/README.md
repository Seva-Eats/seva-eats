# Seva Eats - Agent Skills

This folder contains specialized agent skills that enhance development workflows for the Seva Eats React Native application.

## Available Skills

### 1. **building-native-ui**
Build beautiful, production-grade UI components with Expo Router.
- Covers fundamentals, styling, components, and navigation
- Animations and patterns for native feel
- Use when: Building new screens, improving UI components

### 2. **vibe-security**
Security audit for codebases and vulnerability detection.
- Checks for exposed API keys, broken access control
- Missing auth validation and client-side trust issues
- Insecure payment flows and data exposure
- Use when: Implementing auth, payments, handling user data, or requesting a code security review

### 3. **expo-api-routes**
Guidelines for creating API routes in Expo Router with EAS Hosting.
- Backend route implementation best practices
- EAS hosting integration
- Use when: Adding backend endpoints or API functionality

### 4. **expo-deployment**
Deploy Expo apps to iOS App Store, Android Play Store, and web.
- Build and submission processes
- Certificate and signing setup
- Use when: Preparing for production releases

### 5. **upgrading-expo**
Guidelines for upgrading Expo SDK versions and fixing dependencies.
- Version upgrade paths
- Dependency resolution
- Use when: Updating SDK versions or resolving dependency conflicts

### 6. **use-dom**
Expo DOM components for running web code in webviews.
- Migrate web code to native incrementally
- Use when: Sharing web components with native app or gradual migration

## How to Use These Skills

When working on tasks related to these domains, ask OpenCode to load the relevant skill:

```
"Load the building-native-ui skill for building a new feature screen"
"Use the vibe-security skill to audit authentication code"
"Help me deploy with the expo-deployment skill"
```

The skills provide detailed workflows, code examples, and best practices tailored to your project.
